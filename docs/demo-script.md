# Four-minute demo script

## 0:00–0:35 — Problem and ontology

Show the fragmented supplier, order, shipment, inventory, cost, and document sources. Show
the ontology and state that all personas use one governed semantic view.

## 0:35–1:15 — CoCo lifecycle proof

Show the planning session, CoCo-authored/revised files, deployment commands, query IDs,
test execution, and one failed-then-fixed validation. Do not claim this initial Codex
scaffold as CoCo work.

## 1:15–2:05 — Consistent metrics

Ask the planning, procurement, and logistics versions of the on-time-delivery question.
Show the same numeric result and semantic metric each time. Briefly show fill rate, days of
inventory, and landed cost.

## 2:05–3:05 — Evidence-backed exception

Ask why `SHP-1002` is exceptional. Show the structured route/delivery data, SI versus Draft
BL mismatch, source document path, extracted values, confidence, and evidence. Then show a
missing or unreadable case failing safely into Human Review.

## 3:05–3:35 — Guarded action

Attempt review creation without confirmation and show it blocked. Confirm the action,
create the case, and show actor, timestamp, severity, reason, and source question in the
queue.

## 3:35–4:00 — Unattended operation and close

Show the CoCo automation or fallback Snowflake Task and its latest digest. End with the
new Snowflake core versus pre-existing VeriCargo boundary.
