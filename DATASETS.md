# Dataset and License Inventory

| Dataset | Origin | License / rights | Contains personal data |
|---|---|---|---|
| Supply-chain CSV fixture | Generated by this repository | Team-authored synthetic data | No |
| SI and Draft BL PDFs | Generated by this repository | Team-authored synthetic documents | No |
| Document scenario expectations | Generated by this repository | Team-authored synthetic data | No |
| Deterministic extraction fixtures | Generated alongside the synthetic PDFs for trial-account compatibility | Team-authored synthetic data | No |
| Document file registry | SHA-256 and byte size generated from the synthetic PDFs | Team-authored synthetic metadata | No |

No external or production dataset is required for the MVP. All company names, people,
identifiers, quantities, costs, dates, routes, and document contents are fictional.

`document_extraction_fixtures.csv` is a disclosed deployment fallback for Snowflake trial
accounts that reject `AI_PARSE_DOCUMENT` and `AI_EXTRACT`. It mirrors only the team-authored
synthetic PDFs and does not represent model output. Entitled accounts can switch
`RAW.RUNTIME_CONFIG.DOCUMENT_PROCESSING_MODE` to `AI` and execute the retained native
document-AI procedure.

`document_file_registry.csv` contains only document identifiers, shipment bindings,
document types, filenames, SHA-256 checksums, and byte sizes. It provides reproducible
integrity metadata for the registered demonstration PDFs and the retained future-intake backend.

If an external dataset is added later, record its source URL, version or retrieval date,
license, attribution requirement, and exact fields used before committing it.
